# Security policy

## Supported version

The latest commit on `main` is supported. This is a static portfolio with no account, server-side application state, payment flow, analytics collector, or visitor-submitted content.

## Reporting

Please use GitHub's private vulnerability-reporting feature when available. Otherwise, contact the repository owner through the public GitHub profile without including exploit details in a public issue.

Include the affected route or file, reproduction conditions, impact, and a minimal proof of concept. Do not submit real credentials, private résumé data, customer information, or unrelated personal data.

## Response expectations

Reports are acknowledged after review. Confirmed issues are fixed on `main`, revalidated through CI and CodeQL, and redeployed through the protected Pages workflow.
