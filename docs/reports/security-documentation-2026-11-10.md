## Further fixes discovered during validation

Code Flow Studio's real native check exposed an unbounded Uvicorn wait before
workspace cleanup. Actual loopback reproductions covered a held handler and a
partial body. The fixed service drains HTTP work for five seconds, then cancels
and joins owned HTTP tasks before normal lifespan cleanup. Real local operations
retain their request lock until completion, protecting coherent provider settings
and vault sealing even under repeated cancellation. Local operations can outlive
the HTTP budget; this is not a universal process-exit deadline. Native tests require
actual sealing, thread/main milestones and disappearance of the owned service
processes. The [runtime investigation](https://github.com/JasonStys/code-flow-studio/blob/7d2158a57bb49e8f837fffbfe23b301902465412/docs/reports/native-http-drain-2026-11-10.md)
separates the reproduced mechanism from the unidentified particular connection in
the original hosted failure.

The subsequent release attempt passed all three compiled native builds but stopped
at the final numeric-ID draft lookup. GitHub restricts draft visibility to users
with push access; that job had only content-read permission. The correction scopes
content-write to that verifier job while retaining its read-only implementation,
source/security checks, numeric draft identity and no-overwrite policy. A real
workflow-mutation regression now rejects a return to content-read. The original
command wrapper did not retain the provider's HTTP status, so no specific status
is inferred. The [release workflow report](https://github.com/JasonStys/code-flow-studio/blob/eb9b1cd0c3e3fd1e70e397edeffb059073464f74/docs/reports/draft-release-visibility-2026-11-10.md)
records that boundary and the fresh 0.4.2 version; the unpublished candidate's
assets were preserved rather than overwritten. GitHub's
[release API documentation](https://docs.github.com/en/rest/releases/releases#list-releases)
states the push-access visibility requirement.

The [fresh 0.4.2 release](https://github.com/JasonStys/code-flow-studio/releases/tag/v0.4.2) was published at
2026-11-10T15:21:33Z after the corrected complete release workflow passed.
